## Risco npm temporário

O advisory `GHSA-qwww-vcr4-c8h2` continua atingindo o intervalo publicado de React Router, e 7.18.2
permanece a versão estável `latest`. O Prescripta é uma SPA client-side e não usa RSC Mode, Server
Actions nem action endpoints do router, reduzindo a alcançabilidade conhecida sem alegar correção da
biblioteca. A aceitação pertence ao owner `Soturine`, expira em 15 de agosto de 2026 e é bloqueada
automaticamente por `scripts/check_npm_audit.py` após essa data. A remoção exige uma versão estável
corrigida e compatível ou substituição do roteador.

## Gates executados neste marco

- ambiente Python 3.12 limpo, `pip check` e imports de `certifi`, `cffi`, `cryptography`, `uvicorn`,
  `pydantic` e `pydantic-core`;
- Ruff 0.16.0: aprovado;
- pytest: 191 testes aprovados;
- frontend lint, typecheck, Vitest e build de produção: aprovados;
- `npm audit`: somente o advisory temporário acima, reconhecido pelo gate com expiração;
- Tailwind 4.3.3: build CSS aprovado sem configuração híbrida v3/v4;
- YAML dos workflows válido e todas as 20 referências `uses:` fixadas por SHA completo.

O SBOM frontend é gerado depois de `npm ci`, a partir da árvore efetivamente instalada, com
`--omit optional`, `--output-reproducible` e `--validate`. A omissão é restrita às variantes opcionais
de plataforma do Tailwind Oxide; dependências runtime/dev instaladas permanecem no CycloneDX. Usar
`--package-lock-only` faria `npm ls` interpretar como ausentes dependências que o pacote fallback
WASM declara como bundled, embora elas não integrem a plataforma instalada.
