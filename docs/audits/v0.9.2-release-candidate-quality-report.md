## Evidência remota

CI, Security e Container são executados em paralelo uma vez no push final. A tag não repete essas
suítes: Release Provenance exige os três runs `push` verdes no mesmo SHA e reutiliza seus SBOMs e
relatórios. O GitHub é a fonte de status e identidade desses runs.

## Limites que não mudam

Somente dados sintéticos/demonstrativos. Não há validação epidemiológica, causal, clínica,
regulatória ou institucional. PSM/IPTW são experimentais e `CAUSAL-207` permanece parcial. IA produz
propostas revisáveis; cálculos são determinísticos. NL→SQL permanece desabilitado por padrão.
