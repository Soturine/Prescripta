This register records independently observed gaps. `fixed` requires linked behavior and proof; passing a broad suite alone is not closure. Prescripta remains synthetic/demo-only.

Authorization, deterministic clinical/RWE calculations, FHIR bounded import, evidence SSRF/rights controls, migrations, recovery and agent authority remain in the final regression scope. Existing implementation is not rewritten without a reproducible defect.
