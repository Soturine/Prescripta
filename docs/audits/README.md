# Auditorias e evidências históricas

Este diretório preserva auditorias, revalidações de HEAD, matrizes de fechamento e relatórios
finais. Um relatório histórico descreve o estado e as limitações do SHA indicado; não é
documentação operacional corrente e não deve ser reescrito para sugerir correções retroativas.

Documentação viva do subsistema de auditoria fica em [`docs/auditing`](../auditing/README.md).
