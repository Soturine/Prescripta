# Signal Explorer

Na checagem de prescrição, **Explorar em RWE** transporta somente o ID do achado auditado,
medicamento e desfecho candidato. Em Research, escolha um estudo e confirme a criação: nasce um
draft `proposal`, nunca uma coorte, resultado ou recomendação.

Use Signal Explorer para formular uma pergunta e selecionar dois cohort runs sintéticos do mesmo
snapshot. Revise outcome e Data Quality antes de comparar.
