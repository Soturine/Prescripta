# Plano de análise e resultados

Crie o plano apenas depois de uma execução de coorte. Revise objetivos, variáveis, abordagem de dados
ausentes, métodos, outputs e limitações. Outra pessoa deve revisar o draft antes da execução.

Um finding crítico aberto em Qualidade dos dados bloqueia a análise. Faça acknowledgement somente
quando houver justificativa metodológica; isso não apaga nem reduz a severidade do finding.

Nos resultados, confira população, dados ausentes, média/DP, mediana/quartis/IQR, distribuições,
prevalência com denominador/janela, Table 1 e attrition. “Suprimido” indica uma célula menor que 5.
Incidência aparece como adiada porque a release não valida pessoa-tempo.

O Patient Journey aceita somente paciente e eventos sintéticos comprovados. Se a origem não puder
ser demonstrada, a operação falha fechada.
