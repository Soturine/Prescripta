# Relatório de regressão visual — v0.8.7

## Baseline

Playwright 1.62 mantém snapshots versionados para dashboard profissional, pacientes autorizados e
checagem dimensional. O baseline é produzido no projeto `desktop-chromium`, em Windows, viewport
1440×1000, locale `pt-BR`, tema claro, banco SQLite descartável e seed determinístico.

O CI executa esse baseline em `windows-latest`; os fluxos funcionais, axe, mobile, tablet e reduced
motion continuam no job Linux. Isso evita comparar rasterização de fontes entre sistemas operacionais
como se fosse regressão do produto.

## Estabilidade

- animações e caret são desabilitados pela asserção de screenshot;
- o teste aguarda a animação `.page-enter` atingir opacidade 1;
- workers e banco são únicos, e o backend é recriado por execução;
- conteúdo variável não é necessário nas três páginas baseline;
- tolerância máxima: 1% dos pixels, deliberadamente baixa para acomodar apenas antialiasing residual.

Snapshots ficam ao lado de `e2e/visual-accessibility.spec.ts`. Atualização exige inspeção visual e
execução explícita de `--update-snapshots`; CI nunca aceita automaticamente um novo baseline.

## Evidência complementar

`scripts/capture-current-assets.mjs` gera a vitrine do README com viewports estáveis, motion reduzido,
fontes prontas e detecção de erros de console. `docs/assets/current/manifest.json` registra SHA-256,
dimensões e peso. Essa vitrine não substitui a comparação Playwright.

## Limitações

Não há tema escuro porque o produto não o implementa. Regressão visual não prova semântica,
acessibilidade ou segurança clínica; por isso ela é combinada com axe, Testing Library e E2E reais.
